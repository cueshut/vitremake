Roblox UI library

Build interfaces with a little more life.

Vitality is a configurable Lua UI library for creating clean, expressive Roblox interfaces with controls that feel good to use.

Get vitality.luaSee the example
-- create a window
local Library = loadstring(game:HttpGet(
  LIBRARY_URL
))()

local Window = Library:Window({
  Name = "Vitality"
})

Window:Page({ Name = "Main" })

Made for the whole interface.

Rich controls

Toggles, sliders, dropdowns, labels, popups, keybinds, and more in one consistent system.

Themeable by design

Switch between included presets or shape the palette around your own experience.

Ready to explore

The example file exercises the library's surface so you can start experimenting immediately.
